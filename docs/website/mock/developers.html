Quick start

5 分で動かす

terminal
# Node 22.19+ · pnpm 10
git clone https://github.com/ITC-cloud-soft/biz-ai.git
cd biz-ai
pnpm install
pnpm test        # every workspace package
pnpm validate    # OpenAPI lint + bundled manifests

# the sample business system (PostgreSQL)
pnpm --filter @dsh-bridge/example-equipment-inspection start
→ http://127.0.0.1:19730
server.mjs
import { createBridgeApp, createPool, createPostgresStore } from '@dsh-bridge/server-kit'

const store = createPostgresStore({ pool: await createPool(DB_URL) })
await store.migrate()                 // bridge_* tables
const bridge = await createBridgeApp({
  manifest: { file: './bridge.manifest.yaml' },
  store, serviceToken, bffSecret,
  hooks: { employees, authenticate, isSessionLive,
           recipientsFor, approvals, proposalKinds,
           reports, piiScan },
})
createServer(bridge.handler).listen(8080)
Hooks

業務システムが書くのは hooks だけ

hook返すもの・守ること
employees{ id, role, active }。無効にした職員はすべてのトークンを即時に失う
authenticate既存のセッション → { user: { id, role }, sessionId }。別のログインは作らない
recipientsFornull ／ { stale } ／ { users, paramsFor, link, dedupeKey }。範囲を決め、1 人ずつ Web の認可で確かめる
approvalsget・approvers・card・mayDecide・decide。Web とチャットで同じ規則
proposalKinds{ roles, validate, apply }。apply は人が採用したときだけ、同じトランザクションで
reportscompute(viewer) → 件数だけのセクション
piiScan名簿の名前に当たれば区分だけを返す（文字列は返さない）
