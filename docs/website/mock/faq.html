FAQ

よくある質問

一般

既存システムのコードは変えずに済みますか？

業務ロジックの書き換えは不要ですが、ブリッジ（読む口と提案の口・manifest・本人の SNS 連携・受信者の規則・event の記録など）の追加は必要です。最初の診断で、足すものと量を一覧にします。

新しく作るシステムでも使えますか？

使えます。server-kit の上で作れば、Bridge の部分は部品が持ちます。書くのは業務・hooks・manifest・画面だけです。

どのチャットで使えますか？

Slack・LINE・Microsoft Teams・WeCom・WeChat・Lark など。職員が自分のボットをつなぐ「個人ボット」は 12 種類のチャットに対応しています。email は通知だけに使います。

安全

AI が勝手に承認や支払いをしませんか？

できない作りです。AI の書込みは「提案」だけで、確定・承認・支払・金額の決定は人が業務システムで行います。プロトコルとテストで確かめています。

個人情報はどう扱いますか？

業務の変化の記録（event）と通知には ID・日付・件数だけを載せ、送る前に検査します。AI 社員の記憶にも個人情報は残しません。

グループチャットで業務の話をしても大丈夫ですか？

既定では、グループ会話では業務を扱いません（答えがグループの他の人に見えるため）。AI は固定の案内だけを返し、業務の内容は個別チャットで答えます。

技術

Node.js 以外のシステムでも使えますか？

使えます。Bridge v1（OpenAPI 3.1）をその言語で実装し、52 項目の適合性テストで確かめればつながります。

どの AI モデルを使いますか？

導入先が選べます。AI 面の設定で、使うモデルを指定します。

1 つの AI 面で複数の業務システムを扱えますか？

扱えます。会話・記憶・自動タスク・通知はアプリケーションごとに分かれ、トークンやツールもアプリをまたぎません。

コミュニティとライセンス

ソースコードは見られますか？

GitHub のリポジトリで公開しています。ライセンスはリポジトリの LICENSE をご確認ください。

技術的な質問はどこでできますか？

コミュニティのフォーラムか GitHub Discussions へ。不具合は GitHub Issues へお寄せください。ログや画面を貼るときは、秘密と個人情報を伏せてください。
