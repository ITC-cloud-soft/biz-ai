Capabilities

知らせ、頼み、下書きし、
覚える。

AI 社員の働きは、9 つのプラグインと業務システムの Bridge v1 で組み立てられています。どの機能も「決めるのは人」「本人の権限まで」「関係する人にだけ」を守ります。

🔔

規則ベースの通知

業務の変化を、業務システムが決めた受信者にだけ届ける。モデルが止まっていても届く経路。まとめ送信・おやすみ時間・配信先の優先順位。

提供中
✅

承認カード

承認できる人ごとに 1 枚。ボタンか返信コードで決め、1 人の決定で他のカードはすべて無効。Web と同じ規則で判断。

提供中
📝

AI の提案

AI は書込みの代わりに提案を出す。人が採用したときだけ業務システムが反映。金額は AI が決めない。

提供中
⚙️

自動タスク（playbook）

event や時刻で AI 社員を起こし、読取で確かめ、必要なら提案し、受信者に 1 通だけ報告。委託は仕事の種類ごとに。

提供中
🌅

定時報告

朝と夕方に、本人の 1:1 へ件数のまとめ。起動の直前に本人を確かめ、送る直前に本文を検査。

提供中
🖥️

Web アシスタントと添付

業務 Web のパネルから質問。画像・PDF・Word・Excel を添付でき、文書は保存せずに文字にして渡す。

提供中
❓

使い方の質問（マニュアル）

業務システム自身のマニュアルだけを根拠に、聞いた人が開ける画面の URL 付きで答える。推測では答えない。

提供中
📄

スキャン文書の読み取り

業務システムが読めなかった画像・スキャン PDF を、1 ページずつ書き写して返す。確定は人の確認のあと。

提供中
🔌

外部連携

自社の別 API・第三者の API を接続先として登録。秘密と呼び出しは業務システムだけ。書く操作は人の承認。

提供中
🙂

AI 社員の人柄

会社が決めた呼び名・口調・会社の紹介・性格。規則は変えられず、AI であることを常に示す。

提供中
🧠

長期記憶

個人の記憶・組織の記憶・会話の振り返り。保存前に二重の検査をし、個人情報は残さない。

提供中
🤝

個人ボットと複数アプリ

職員が自分のボットを 12 種のチャットでつなげる。1 つの AI 面に複数の業務システム、会話はアプリごとに分離。

提供中
